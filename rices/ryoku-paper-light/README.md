# Ryoku Paper Light

A light editorial Ryoku rice: warm washi surfaces, bronze accents, a left rail,
and a classical marble statue against a soft Great Wave print.

## Wallpapers

Ryostore installs the marble-statue wallpaper automatically:

- `ryoku-paper-light-stoic-wall.png` — https://github.com/eduardojvieira/ryostore/releases/download/rices/ryoku-paper-light-stoic-wall.png
