# Nothing Interface for Ryoku

Community rice by Ivan. A fixed charcoal and grey palette, three island QS Bar
layout, and Noto Sans typography inspired by Nothing OS. The rice does not
install or change a wallpaper. It is an independent fan project and is not
affiliated with Nothing Technology Limited.

This store item installs the Ryoku rice and palette. For the complete desktop,
install the related Ryostore plugins `nothing-analog-clock`, `nothing-dashboard`,
`nothing-media`, `nothing-screen-time`, and `nothing-status`; `nothing-audio` is
optional. The matching `nothing-interface` lockscreen is a separate store item.
The extra QML overrides for the large dotted desktop clock, bar clock, and
launcher mark, plus the 1920 × 1080 widget layout guide, are documented in the
[upstream project](https://github.com/venchik111/ryoku-nothing-interface).
Ryostore's rice format does not install those overlays or position the plugins.

Built with Ryoku 0.75.3. Save your current rice before applying. On another
screen size, place the widgets in Ryoku Hub → Widgets. Adjust the bar in QS Bar
Settings → Bars / Layout / Community. The optional AI-generated wallpapers
linked from the upstream project are not bundled with this store item.
