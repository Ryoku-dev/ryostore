# Ryoku Paper Dark

A dark editorial Ryoku rice: charcoal washi surfaces, bronze accents, a left
rail, and a classical marble statue against a subdued Great Wave print.

## Wallpapers

Ryostore installs the marble-statue wallpaper automatically:
