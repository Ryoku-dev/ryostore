# Ryoku Paper Dark

A dark editorial Ryoku rice: charcoal washi surfaces, bronze accents, a left
rail, and a marble family portrait as its primary wallpaper.

## Wallpapers

Ryostore installs the primary family wallpaper automatically:

- `ryoku-paper-dark-wall.png` — https://github.com/eduardojvieira/ryostore/releases/download/rices/ryoku-paper-dark-wall.png

The stoic marble alternative uses the same composition without family likenesses:

- `ryoku-paper-dark-stoic-wall.png` — https://github.com/eduardojvieira/ryostore/releases/download/rices/ryoku-paper-dark-stoic-wall.png

Ryostore currently accepts one wallpaper per rice. To use the alternate, download
it from the link above and select it in Ryoku's wallpaper picker after applying
the rice.
