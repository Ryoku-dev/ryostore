# Ryoku Discord

A Vesktop/Vencord theme based on [Ron’s original Ryoku theme](https://github.com/niqqudim/ryoku-discord). This adaptation adds optional live Ryoku palette colors and reduced motion support. The original design and artwork belong to the upstream project.

Install through Ryostore, then enable `Ryoku.theme.css` in **Vesktop Settings → Vencord → Themes**. You can also copy the CSS file into Vesktop’s themes folder manually. Disable other full themes, including Midnight Ryoku, so their layout rules do not overlap.

To follow the Ryoku wallpaper palette, open **Super+W → Settings → Ryoku Palette Bridge → App integrations → Vesktop** and choose **SET UP**. The bridge keeps Vencord QuickCSS enabled and writes the current colors there. Choose **REMOVE** to return to the theme’s red and gold palette. The theme stays enabled.

The screenshot in `assets/preview.png` comes from the [original theme](https://github.com/niqqudim/ryoku-discord) and shows its default appearance.
