# 43PR Readout

43PR's hardware/software sections and Nerd Font keys, adapted for Ryoku's
Fastfetch category. Uses the system's built-in logo instead of the upstream personal
image path. Install and select it in Ryoku Hub > Fastfetch.

Only native Fastfetch modules run: CPU, GPU, memory, OS, kernel, window manager,
theme, icons, font, terminal and shell. No command modules, scripts, network
access or external image files. Main names are truncated to keep the readout
inside its width budget. Colors follow the terminal's ANSI palette, not a
separate theme daemon. Use a Nerd Font for the icons.
