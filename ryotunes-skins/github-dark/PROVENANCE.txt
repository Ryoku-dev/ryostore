Skin: GitHub Dark (github-dark)
Provider: Noctalia
Upstream palette: GitHub Primer <https://github.com/primer/github-vscode-theme>
Source: Ryoku colour-scheme catalogue (colorschemes/github-dark)
        https://raw.githubusercontent.com/ryoku-dev/ryostore/main/colorschemes/GitHub%20Dark/preview.jpg
License: CC0-1.0

Derived by tools/import-ryotunes-skins.py, mapping the Noctalia palette
onto Ryotunes' eight skin roles, per mode:
  paper     = mSurface
  paperLift = mSurfaceVariant or mHover, whichever is closest in
              luminance to mSurface without equalling it
  ink       = mOnSurface
  inkDim    = mOnSurfaceVariant
  bone      = mOnSurface
  inkOnBone = mSurface
  sun       = mPrimary
  alert     = mError

Only the eight colour roles are set; type, shape, motion and decor are
left to Ryotunes' Paper defaults.
