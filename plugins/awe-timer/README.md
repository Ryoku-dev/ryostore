# Timer

A Ryoku desktop widget ported from **Awe** (github.com/neur0map/MJ-widgets), released under BSL-1.0.

Focus (25m), break (5m), stopwatch and custom durations with a circular
progress ring. The chosen mode and duration are persisted to
`$XDG_STATE_HOME/ryoku/plugins/awe-timer/state.json` so they survive a reload.

No network access and no external commands.
