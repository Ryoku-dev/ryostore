# Crypto

A Ryoku desktop widget ported from **Awe** (github.com/neur0map/MJ-widgets), released under BSL-1.0.

Prices for Bitcoin, Ethereum and Solana are polled once a minute with `curl`
from the **CoinGecko** public API, with 24h change and a sparkline per coin.

Network: `api.coingecko.com`. Nothing is written to disk.
