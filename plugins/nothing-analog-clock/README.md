# Nothing Analog Clock

An analog desktop clock inspired by the user's Nothing OS reference screenshot.
It uses a charcoal circular face, neutral tick marks and a single N-Red second
hand. The dial is drawn in QML; no proprietary clock artwork is bundled.

The widget reads the local system clock. It runs no external commands, uses no
network access and writes no files. It is installed locally as a Ryoku desktop
widget. Its preview is a capture of the running widget.
