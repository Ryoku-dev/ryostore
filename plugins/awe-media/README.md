# Media

A Ryoku desktop widget ported from **Awe** (github.com/neur0map/MJ-widgets), released under BSL-1.0.

It reflects the active MPRIS player through `playerctl metadata` and drives
playback with `playerctl play-pause / next / previous / position`. Album art
is loaded straight from the player's `mpris:artUrl`.

No network access and nothing is written to disk.
