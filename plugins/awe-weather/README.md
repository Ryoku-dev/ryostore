# Weather

A Ryoku desktop widget ported from **Awe** (github.com/neur0map/MJ-widgets), released under BSL-1.0.

Current conditions are fetched with `curl` from **wttr.in** every 15 minutes
(and again whenever you click the card). Temperature, condition, wind and
humidity come back in a single compact format string.

Network: `wttr.in`. Nothing is written to disk.
